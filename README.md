# 家常菜谱集（home-recipes）

妈妈模式 · 饮食的菜谱积累，单页静态站，数据内嵌于 `index.html`，原生 JS，无框架。

- 线上：https://joe12-24.github.io/home-recipes/
- 内容：30 道菜谱 + 2 篇讨论（川菜 3 / 湘菜 3 / 家常 24 / 火锅讨论 2：川渝火锅、潮汕牛肉火锅；其中 10 道为阿斯利康食堂同款家常菜），带材料、步骤时长、火候提醒、关键技巧、采购提示
- 功能：搜索（菜名/食材/品牌）、三组筛选（菜系/类型/口味）、详情弹层、深色模式、响应式（手机单列 / Pad 双列 / 桌面三列）
- 本地预览：直接用浏览器打开 `index.html` 即可
